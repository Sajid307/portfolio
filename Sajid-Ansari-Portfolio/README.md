# Sajid Ansari Portfolio

A modern React + TypeScript portfolio for Sajid Ansari, focused on Java backend engineering, distributed systems, projects, experience, and LeetCode progress.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This is a static Vite application and can be deployed to GitHub Pages, Vercel, Netlify, or any static hosting provider.

### GitHub Pages

Build with:

```bash
npm run build
```

Then publish the `dist` directory using GitHub Pages or a Pages deployment action.

## Update personal links

Edit `src/data/profile.ts`.

The LeetCode dashboard uses assets from:

`https://github.com/Sajid307/leetcode`

so your existing LeetCode GitHub Action can continue updating the SVGs without requiring changes to this portfolio.
